# Ôn tập JSB Buổi 1–5

Website ôn tập tương tác HTML/CSS cho JSB Web Developer Basic, gồm kiến thức Buổi 1–5, ví dụ code có output, mini-project, bài tập thực hành, checklist debug và câu hỏi tự ôn.

## Chạy website

Khuyến nghị dùng **VS Code + Live Server** hoặc bất kỳ static web server nào.

```text
index.html
styles.css
app.js
loader.js
content/
  00-overview.html
  01-buoi-1.html
  02-buoi-2.html
  03-buoi-3.html
  04-buoi-4.html
  05-buoi-5.html
  06-practice.html
  07-review.html
```

- `index.html`: khung giao diện chính.
- `styles.css`: giao diện responsive/light-dark.
- `loader.js`: nạp nội dung từng chương.
- `app.js`: tìm kiếm, preview code, copy code, theme, progress và tương tác.
- `content/`: nội dung học tập theo từng phần để dễ đọc và chỉnh sửa trên GitHub.
