# JSB Review CP1 — Buổi 1–5

Website ôn tập tương tác cho JSB Web Developer Basic, bám theo tài liệu Buổi 1–5: HTML cơ bản, Semantic HTML, CSS/Selector/Box Model, Cascade/Position, Display/Responsive/Flexbox, mini-project, bài tập, checklist debug và câu hỏi tự ôn.

## Cấu trúc

```text
index.html      # Khung giao diện
styles.css      # UI responsive + light/dark
app.js          # Render Markdown, search, code lab, output preview
content/        # Nội dung gốc chia theo chương
```

## Chạy local

Dùng **VS Code + Live Server** (không mở trực tiếp bằng `file://` vì nội dung được tải bằng `fetch`).

## Deploy

Repo là static website, có thể deploy trực tiếp bằng GitHub Pages, Netlify hoặc Vercel.
