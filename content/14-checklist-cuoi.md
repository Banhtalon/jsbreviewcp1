# 13. Checklist hoàn thành cuối cùng

- [ ] Dự án mở được bằng Live Server.
- [ ] Có đúng `<!DOCTYPE html>`.
- [ ] Có `lang="vi"`.
- [ ] Có `charset`.
- [ ] Có viewport meta tag.
- [ ] Có tiêu đề tab phù hợp.
- [ ] HTML được thụt lề rõ ràng.
- [ ] Ảnh có `alt`.
- [ ] Liên kết hoạt động.
- [ ] CSS được đặt trong file riêng.
- [ ] Selector đúng với HTML.
- [ ] Không lạm dụng ID.
- [ ] Box Model hợp lý.
- [ ] Không có width cố định gây tràn.
- [ ] Position có mốc định vị đúng.
- [ ] Flexbox được đặt ở phần tử cha.
- [ ] Có `flex-wrap` khi cần.
- [ ] Có Media Query.
- [ ] Website không tràn ngang trên mobile.
- [ ] Đã kiểm tra bằng DevTools.
- [ ] Có thể tự giải thích code của mình.

---

> **Ghi nhớ:** Mục tiêu không phải là thuộc lòng mọi dòng code. Mục tiêu là hiểu mỗi thẻ và mỗi thuộc tính đang giải quyết vấn đề gì, sau đó tự kết hợp chúng để xây dựng giao diện.
