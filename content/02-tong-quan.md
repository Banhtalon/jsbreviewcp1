# 1. Tổng quan kiến thức Buổi 1–5

## 1.1. Lộ trình năm buổi

| Buổi   | Chủ đề chính                                | Sản phẩm thực hành                |
| ------ | ------------------------------------------- | --------------------------------- |
| Buổi 1 | Website, VS Code, HTML cơ bản               | Website giới thiệu bản thân       |
| Buổi 2 | HTML bậc trung, website nhiều trang         | Portfolio Website                 |
| Buổi 3 | CSS, Selector, DevTools, Box Model          | Trang web được trang trí bằng CSS |
| Buổi 4 | Độ ưu tiên CSS, kế thừa, Position           | The Flag hoặc giao diện định vị   |
| Buổi 5 | Display, Responsive, Media Queries, Flexbox | Checkpoint 1                      |

## 1.2. Checklist năng lực cần đạt

Sau khi ôn xong, bạn nên tự làm được các mục sau:

- [x] Giải thích được website là gì.
- [ ] Phân biệt được website và webpage.
- [ ] Trình bày được vai trò của HTML, CSS và JavaScript.
- [ ] Mô tả được quá trình trình duyệt tải một website.
- [ ] Tổ chức được thư mục dự án rõ ràng.
- [ ] Sử dụng VS Code và Live Server.
- [ ] Viết đúng bộ khung HTML5.
- [ ] Dùng được tiêu đề, đoạn văn, danh sách, ảnh và liên kết.
- [ ] Tổ chức trang bằng các thẻ semantic.
- [ ] Tạo được website nhiều trang.
- [ ] Liên kết đúng file HTML, CSS và ảnh.
- [ ] Viết được CSS bằng tag, class và ID selector.
- [ ] Hiểu Box Model.
- [ ] Dùng DevTools để kiểm tra CSS.
- [ ] Hiểu độ ưu tiên, thứ tự khai báo và tính kế thừa.
- [ ] Phân biệt `static`, `relative`, `absolute` và `fixed`.
- [ ] Phân biệt `block`, `inline`, `inline-block` và `none`.
- [ ] Tạo bố cục bằng Flexbox.
- [ ] Viết Media Query đơn giản.
- [ ] Xây dựng giao diện không bị tràn trên điện thoại.

